# Changelog

All notable changes to SnoozeEscape are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-19

### Added

- Interactive bedroom desk scene with a live digital alarm clock.
- Nine randomized alarm escape behaviors and an eight-attempt ending.
- Web Audio alarm, volume and mute controls, and reset functionality.
- Responsive mouse, keyboard, and touch interaction.
- Reduced-motion support and accessible live status announcements.
- Dependency-free validation and GitHub Pages-ready static deployment.
