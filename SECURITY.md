# Security Policy

## Supported versions

Security fixes are applied to the current release.

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** security-advisory form once the repository is public. Until then, contact `sunny.sudarshan@gmail.com` with the repository name and a concise reproduction.

Do not open a public issue for a vulnerability. Reports should avoid real credentials or personal data. SnoozeEscape has no backend, accounts, data storage, analytics, or third-party runtime dependencies, so its main security surface is browser-delivered HTML, CSS, and JavaScript.
